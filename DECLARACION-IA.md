# Declaración de Uso de Inteligencia Artificial

Para el desarrollo de **PokeOracle** se utilizaron asistentes de inteligencia artificial, entre ellos **Cursor**, con los siguientes propósitos:

1. **Diseño Arquitectónico** — Elaboración de diagramas C4 y estructuración del proyecto bajo Clean Architecture.
2. **Documentación Técnica** — Redacción de la evaluación ATAM y documentación complementaria del sistema.
3. **Automatización** — Configuración del pipeline de integración continua (CI) en GitHub Actions.
4. **Testing** — Generación y organización de la base de pruebas unitarias con xUnit.

**Nota:** Toda la lógica de dominio, la matemática del algoritmo Expectiminimax y las decisiones estructurales del proyecto fueron revisadas y autorizadas por el desarrollador para cumplir con los estándares del curso.
